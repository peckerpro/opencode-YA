# v0.3 Plan - Extensibility, Root Control and Project Workspaces

## Milestone Goal

增加 MCP、Skill、自定义工具、TUI、GitHub memory sync、scheduler integrations，以及 Root Agent 的 session 控制和 project workspace。

## Non-goals

- 不实现完整自动 multi-agent worker runtime。
- 不实现完整 Planner/Coding/Review/Test/Document team 自动编排。
- 不默认信任 community MCP/Skill。
- 不允许无授权 shell、删除或 Git push。
- 不实现完整多模态 ingest。

## Definition of Done

- V3-001 至 V3-010 Done。
- community integration 默认 disabled。
- scheduler 的危险任务使用持久权限 profile，失败有熔断和有限 retry。
- Git 冲突不静默覆盖。
- CLI/TUI/Web 使用同一 application services。
- Root Agent 的 send/spawn/lifecycle action 经过 capability、确认和 audit。
- Project workspace 与其他 project/session 隔离。
- 生成 `reports/v0.3-alignment.md`。

## V3-001 - MCP Client and Registry Integration

### 目标

通过 stdio 接入 allowlisted MCP server，并把工具注册到统一 registry。

### 输入

`docs/MCP_AND_SKILLS.md`、`docs/SECURITY.md`。

### 文件范围

MCP port/stdio adapter、registry integration、CLI 和测试。

### 实现要求

server 配置、环境 allowlist、lifecycle、tool discovery、timeout、schema 和日志。

### 测试要求

fake server、启动失败、malformed schema、timeout、权限拒绝和 secret isolation。

### 验收标准

MCP tool 不能绕过 registry/policy；server 默认 disabled。

### 不做

HTTP/SSE transport 和 OAuth。

### 输出

client、CLI、测试和 server config schema。

## V3-007 - Scheduler Integrations and Hardening

### 目标

增加 memory sync/GitHub push、RAG re-index、allowlisted MCP tool 和高级运行控制。

### 输入

`docs/SCHEDULER.md`、V3-001、V3-005、v0.2 scheduler/RAG。

### 文件范围

scheduler executors、permission profile、breaker、retention、CLI/TUI/Web 状态和测试。

### 实现要求

- 新 job type 使用 typed executor。
- Git push、外部 MCP 和高风险写入要求持久授权。
- job 固定/记录外部 tool/skill 版本。
- circuit breaker、log retention 和有限 catch-up。
- TUI/Web 显示风险、next run、last run 和 logs。
- 防止 scheduler-origin run 创建自触发链。

### 测试要求

Git conflict、MCP failure、RAG lock、权限撤销、breaker、retention、版本变化和递归链。

### 验收标准

无授权危险 job 被阻止；失败不无限 retry；自调用链被终止并审计。

### 不做

通用 shell cron、无上限 catch-up 和 scheduled Root Agent 跨 session orchestration。

### 输出

integrations、UI 状态、测试和 operator guide。

## V3-008 - Root Session Control and Instructions

### 目标

实现 Root Agent 的跨 session instruction、spawn、pause、resume、archive 和 close。

### 输入

`docs/AGENT_ROLES_AND_PERMISSIONS.md`、v0.2 session registry/Root read、`docs/SECURITY.md`。

### 文件范围

Instruction domain/store/queue、session lifecycle service、permission confirmation、Root CLI/API/TUI/Web 和测试。

### 实现要求

- 持久化 `Instruction` source、target、status、result 和 permission decision。
- 实现 `ya root send/spawn/pause/resume/archive/close`。
- send 经 `session.instruction.send` guard；目标 session 重新验证并按自身权限执行。
- lifecycle action 使用独立 capability 和 confirmation policy。
- paused/archived/closed 对 instruction/run 有确定行为。
- Root Agent 所有 action 写 append-only audit。
- hard delete 不在本任务范围。

### 测试要求

send success/reject/cancel、target closed、spawn、状态转换、confirmation allow/deny/expiry、权限撤销、audit correlation 和中文 instruction。

### 验收标准

Root action 可追踪；目标 Session Agent 不继承 root capability；未确认高危 action 被拒绝；Session Agent 不能调用 Root action。

### 不做

Project multi-agent team、hard delete 和 autonomous cross-session scheduling。

### 输出

Instruction/lifecycle service、Root interfaces、audit/permission 测试和 operator guide。

## V3-009 - Project and Workspace Management

### 目标

允许 Root Agent 创建隔离的 Project/Workspace 和 project session，为 v0.4 team runtime 建立边界。

### 输入

V3-008、`docs/AGENT_ROLES_AND_PERMISSIONS.md`、workspace architecture。

### 文件范围

Project/Workspace domain/store/application、Root CLI/API/UI、模板和测试。

### 实现要求

- 创建/list/inspect/archive Project 和 project workspace。
- project workspace 固定 canonical root、task board、whiteboard、reports 和 locks。
- session/task 可绑定 project/workspace。
- Root Agent 使用 `project.create` 等 capability；高影响路径需要确认。
- 不同 project 默认互不可见。
- project template 使用 UTF-8，不包含 secret。

### 测试要求

创建、重复名称/ID、路径 traversal/symlink、project isolation、archive、Root allow/deny、Session Agent 拒绝和 audit。

### 验收标准

Project workspace 隔离成立；Session Agent 不能创建或访问其他 project；所有 project 管理 action 可审计。

### 不做

不自动 spawn Planner/Coding/Review/Test/Document/Coordinator team。

### 输出

Project/Workspace service、interfaces、模板、隔离测试和 handoff。

# Runtime Task Board

> Scope: 当前由 YA runtime 管理的项目。不要在这里维护 YA 仓库自身的开发路线。

## Rules

- task package 必须有 ID、owner、status、blocked reason、输入、输出、测试和验收标准。
- 每个 task 必须绑定 session/project/workspace scope 和执行 role。
- claim/transition 通过 Coordinator 或 `ya task` 命令执行。
- 一个 owner 同时只能持有允许数量的任务；Coding 默认一个。
- Done 必须链接 test evidence。
